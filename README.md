# Презентация AI-консультанта B24U

Материалы для первой встречи с клиентом: веб-версия презентации и исходники слайдов.

## Что внутри

- `index.html` — веб-версия презентации. Одна страница с прокруткой: обложка, боли клиента, сетка 168 часов, пример диалога, результат до/после, тарифы, запуск, контакты.
- `img/` — фотографии для обложки и финала.
- `slides/` — исходники слайдов деки (по одному HTML на слайд) и `deck.json` с порядком.

## Данные, которые стоит проверить перед встречей

- Средний чек клиента — от него считается окупаемость тарифа (сейчас в примере 35 000 ₽).
- Тариф, с которого доступна интеграция с CRM: на лендинге заявлен второй уровень, в партнёрском кабинете у Pro она внутри дополнительных функций.
- Цены в рублях пересчитаны по курсу 82,90 ₽ за доллар на 20.10.2026.
